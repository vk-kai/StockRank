# 小程序内容安全代理接口（StockRank 后端）

为小程序《每日热门趣味测试》过审提供的微信内容安全 API 服务端代理。
access_token / appsecret 只能服务器端使用，所以由 StockRank 后端统一转发。

- 代码：`backend/routes/mp_sec_routes.py`
- 配置：`config/mp_sec_config.json`
- 蓝图前缀：`/api/mp/sec`（已放行登录拦截，接口自带 auth_key 校验）

## 配置项说明（config/mp_sec_config.json）

| 字段 | 说明 |
|---|---|
| appid | 小程序 AppID（微信公众平台 → 开发 → 开发设置） |
| appsecret | 小程序 AppSecret（同上，重置后要同步改这里） |
| push_token | 消息推送 Token。**原样复制到微信后台"消息推送"配置里**，两边必须一致 |
| auth_key | 小程序调用这些接口的共享密钥，请求头 `X-Auth-Key` 携带，可自行换 |
| media_base_url | 服务器公网 HTTPS 前缀（如 `https://xxx.com`），上传接口拼公网文件 URL 用 |

改完配置必须重启后端生效。

## 微信后台一次性配置

1. **消息推送**（微信公众平台 → 开发 → 开发设置 → 消息推送）：
   - 服务器 URL：`https://你的域名/api/mp/sec/callback`
   - Token：`fc3496790b79e16a67beaf59caa438f3`（与配置文件 push_token 一致）
   - 数据格式：**JSON**；消息加解密方式：**明文模式**
   - 点"启用"时微信会 GET 该 URL 做验证，后端已在跑即可通过
2. **request 合法域名**（开发设置 → 服务器域名）：把 StockRank 后端的 HTTPS 域名加入

## 接口列表

所有业务接口要求请求头 `X-Auth-Key: <auth_key>`（放在 body 里 `auth_key` 字段也行）。

### 1. POST /api/mp/sec/login — code 换 openid

```json
{ "code": "wx.login拿到的code" }
→ { "success": true, "openid": "oXXXX", "session_key": "..." }
```

openid 对应用户需**近 2 小时内访问过小程序**，送检接口才能用。

### 2. POST /api/mp/sec/msg-check — 文本检测（同步，msgSecCheck 2.0）

```json
{ "openid": "oXXXX", "content": "待检测文本", "scene": 1 }
→ { "success": true, "safe": true, "suggest": "pass", "label": 100, "label_name": "正常", "detail": [...] }
```

- scene：1 资料 / 2 评论 / 3 论坛 / 4 社交日志，默认 1
- `safe` 仅当 `suggest == "pass"` 为 true；`review`（人审）/ `risky`（违规）均为 false

### 3. POST /api/mp/sec/upload — 上传图片/音频（multipart form-data）

| 字段 | 说明 |
|---|---|
| file | 文件（≤10M；图片 jpg/jpeg/png/bmp/gif；音频 mp3/aac/ac3/wma/flac/ogg/opus/wav） |
| auto_check | 可选，传 1 则上传后立即送检，直接返回 trace_id |
| openid | auto_check=1 时必须传 |
| scene | 可选，默认 2（评论） |

```json
→ { "success": true, "media_url": "https://域名/api/mp/sec/media/20260819/xxx.png", "media_type": 2,
     "trace_id": "...", "status": "checking" }
```

### 4. POST /api/mp/sec/media-check — 送检已有公网 URL 的媒体（mediaCheckAsync 2.0）

```json
{ "openid": "oXXXX", "media_url": "https://任意可公网下载的地址/1.png", "scene": 2 }
→ { "success": true, "trace_id": "xxx", "status": "checking" }
```

`media_type` 可省略（按 URL 后缀自动判断）。media_url 必须让微信服务器能直接下载。

### 5. GET /api/mp/sec/media-result?trace_id=xxx&wait=15 — 查异步结果

`wait` 秒内长轮询（0~30s），建议 15s。

```json
→ { "success": true, "status": "pass", "label": 100, "label_name": "正常", "detail": [...], "received_at": "..." }
```

status：`checking`（检测中）/ `pass` / `risky` / `review` / `error`（含微信侧下载失败 -1008）/ `not_found`

### 6. /api/mp/sec/callback — 微信推送接收（微信服务器调用，勿手动调）

GET = 消息推送 URL 验证（echostr 回显）；POST = `wxa_media_check` 异步结果落库。
带 push_token 签名校验。

## 小程序端调用示例

```js
const BASE = 'https://你的域名/api/mp/sec'
const KEY = 'c1a62b1dedfc6ac2c076010f220b9ed8'

// 登录换 openid（可 wx.login 后端到端完成）
function login() {
  return new Promise((resolve, reject) => {
    wx.login({
      success: async ({ code }) => {
        const res = await wx.request({
          url: `${BASE}/login`, method: 'POST',
          header: { 'X-Auth-Key': KEY, 'content-type': 'application/json' },
          data: { code }
        })
        resolve(res.data.openid)
      },
      fail: reject
    })
  })
}

// 九宫格图片送检：选图 → 上传并自动送检 → 轮询结果
async function checkImage(openid, filePath) {
  const up = await new Promise((resolve, reject) => {
    wx.uploadFile({
      url: `${BASE}/upload?auto_check=1&openid=${openid}`,
      filePath, name: 'file',
      header: { 'X-Auth-Key': KEY },
      success: (r) => resolve(JSON.parse(r.data)),
      fail: reject
    })
  })
  if (!up.success) throw new Error(up.errmsg || '上传失败')
  // 长轮询结果（微信异步推送，通常几秒内）
  for (let i = 0; i < 4; i++) {
    const r = await new Promise((resolve) => {
      wx.request({
        url: `${BASE}/media-result?trace_id=${up.trace_id}&wait=15`,
        header: { 'X-Auth-Key': KEY },
        success: (res) => resolve(res.data),
        fail: () => resolve({ status: 'checking' })
      })
    })
    if (r.status === 'pass') return true
    if (r.status === 'risky' || r.status === 'review') return false
    if (r.status === 'error') throw new Error('检测失败')
    // checking → 继续下一轮
  }
  return false // 超时按不通过处理（审核要求从严）
}

// 用法：不通过时仅提示"内容含违规信息"（审核明确要求只需这样提示）
// wx.showToast({ title: '内容含违规信息', icon: 'none' })
```

## 运维备忘

- access_token 用 stable_token 接口 + 文件缓存（`data/mp_sec_token.json`），重启不浪费额度，40001/42001 自动强刷重试
- 异步结果落 `data/mp_sec_results.json`（保留最近 500 条）；上传文件存 `data/mp_sec_media/`
- 频率限制（微信侧）：单 appid 2000 次/分钟、20 万次/天、单文件 ≤10M
- 测试：`python -m unittest tests.test_mp_sec`（16 个用例）
